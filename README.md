# 糖友健康小程序

一个适合糖尿病人使用的微信小程序，聚焦于健康管理与日常提醒。

## 功能
- 血糖记录与趋势展示
- 饮食管理与推荐
- 用药提醒设置
- 运动记录
- 健康知识学习
- 社区交流入口

## 设计主题
- 主色：绿色
- 辅色：白色、淡黄色
- 风格：温和、治愈、专业

## 运行方式
1. 打开微信开发者工具
2. 导入当前项目目录
3. 选择微信小程序项目
4. 点击预览即可运行

## 目录说明
- `pages/`：页面模块
- `utils/`：公共数据和工具函数
- `app.js`：全局逻辑
- `app.json`：配置文件
- `app.wxss`：全局样式
